---

## ✨ Sobre o Projeto

Este é o meu portfólio oficial, criado para apresentar minhas habilidades, projetos e trajetória como desenvolvedor web. O site possui:

- Design dark com tema vermelho neon
- Animações suaves e efeitos de partículas
- Cursor personalizado
- Layout 100% responsivo
- Tipagem automática no hero
- Sistema de scroll reveal
- Lightbox na galeria
- Contadores animados
