## ✨ Sobre o projeto

Este é o meu portfólio oficial, criado para apresentar minhas habilidades, projetos e trajetória como desenvolvedor web. Foi construído **100% com tecnologias web puras** (HTML, CSS e JavaScript), com visual **dark cyberpunk em vermelho neon**, totalmente responsivo e cheio de microinterações.

> 💡 Projeto feito **sem frameworks** — apenas Vanilla JS.

## 🚀 Como rodar localmente

**1. Clone o repositório**

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

**2. Abra o projeto** (escolha uma opção)

- **Mais simples:** dê dois cliques no `index.html` para abrir no navegador.
- **Com Live Server (VS Code):** instale a extensão *Live Server*, clique com o botão direito em `index.html` e escolha **Open with Live Server**.
- **Com Python:**

  ```bash
  python -m http.server 5500
  ```

  Depois acesse `http://localhost:5500`.

> Não precisa instalar dependências nem rodar build. 🎉

## 🎨 Personalização

As cores do tema ficam em variáveis CSS, então dá para mudar o visual inteiro em poucos segundos. Exemplo (ajuste o nome das variáveis conforme o seu CSS):

```css
:root {
  --bg: #0d0d0d;
  --accent: #ff1a1a;
  --accent-dark: #8b0000;
  --gold: #ffd700;
}
```
